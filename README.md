# Learning Journal

A personal knowledge base for storing things I learn. Built with interconnected Markdown files for easy navigation, similar to Obsidian.

## How to Use This Repository

This repo is designed to work seamlessly with **Obsidian** (free note-taking app).

### Setting up in Obsidian
1. Clone the repository:
   ```bash
   git clone https://github.com/learnda1ly/learning-journal.git
   ```
2. Open Obsidian → **Open folder as vault** → Select the cloned `learning-journal` folder.
3. Obsidian will automatically recognize internal wiki-style links (`[[Link to Note]]`).

### Recommended Structure
- `Notes/` - Main learning notes
- `Topics/` - Index/MOC pages by subject
- `Daily/` - Daily notes (optional)
- `Attachments/` - Images, PDFs, etc.
- `Templates/` - Reusable note templates

## Instructions for Grok (AI Assistant)

**Grok's Guidelines for this Repository:**

1. **Markdown + Wiki Links**: Always create new notes as `.md` files using Obsidian-compatible wiki links `[[Note Title]]`.
2. **Interconnected Notes**: When adding content, include relevant links to existing or new notes.
3. **Folder Structure**: Prefer the structure above. Create index/MOC (Maps of Content) pages in `Topics/`.
4. **Atomic Notes**: Encourage one idea per note when possible.
5. **When User Asks**:
   - Suggest new note titles with links.
   - Offer to create/update specific `.md` files.
   - Maintain consistency with Obsidian linking.

Use `[[Note Name]]` for links. For folders use `[[Folder/Note]]`.
